CAR DHUNDHO
1) Install Node.js (LTS) from nodejs.org
2) In this folder run:  npm install   then   npm start
3) Open http://localhost:3000
Accounts -> data/users.json, enquiries -> data/enquiries.json (created automatically).
Without the server (opening public/index.html directly) Sign In and forms still work in demo mode (browser only).
Car photos load automatically from Wikipedia (needs internet). To use your own, save public/images/cars/<car-id>.jpg - it takes priority.

Car photo file names (public/images/cars/): tesla-model-s, hyundai-creta, mahindra-xuv700, tata-nexon, maruti-swift, toyota-innova, mahindra-thar, skoda-kushaq, vw-taigun, mercedes-c-class, honda-city, kia-sonet (.jpg)
